THU Grade Scraper

THU Grade Scraper 是一個專為東海大學（Tunghai University）學生設計的 Python 工具， 透過 Selenium 自動登入東海大學學生資訊系統，擷取成績資料後進行計算與視覺化呈現， 讓學生能快速掌握自己的 GPA 與各科成績概況。

功能特色

  • 自動登入：使用 Selenium 自動化登入東海大學學生入口網站。
  • 成績擷取：自動抓取各學期、各科目的成績資料。
  • GPA 計算：根據學分加權自動計算累計 GPA。
  • 成績分析：統計各分數區間分佈，提供清晰的成績報表。
  • 資料視覺化：使用 Matplotlib 繪製成績趨勢圖與分佈圖。
  • CSV 匯出：可將成績資料匯出為 CSV 檔案，方便後續分析。

安裝需求

  • Python 3.8 以上版本
  • Google Chrome 瀏覽器 + ChromeDriver（版本需對應）
  • 所需套件：selenium、pandas、matplotlib

安裝相依套件：

pip install selenium pandas matplotlib

使用說明

1. 克隆專案

git clone https://github.com/Caspar15/thu-grade.git
cd thu-grade

2. 設定帳號

於 config.py（或直接在 main.py）中填入您的東海大學學號與密碼：

USERNAME = "你的學號"
PASSWORD = "你的密碼"

3. 執行腳本

python main.py

程式將自動啟動 Chrome，登入學生系統，擷取所有學期成績，並輸出分析結果。

項目結構

thu-grade/
├── main.py           # 主程式入口
├── scraper.py        # Selenium 爬蟲模組
├── calculator.py     # GPA 計算與成績分析
├── visualizer.py     # Matplotlib 視覺化模組
├── config.py         # 帳號設定（請勿上傳至 GitHub）
├── output/
│   ├── grades.csv    # 匯出的成績資料
│   └── chart.png     # 成績趨勢圖
└── README.md

注意事項

  • 本工具僅供個人學術用途，請勿濫用或用於非法目的。
  • 帳號密碼儲存於本機設定檔，請確保 config.py 不被提交至版本控制。
  • 網站介面若有異動，可能需要更新 CSS Selector 以維持正常運作。
  • ChromeDriver 版本需與本機 Chrome 版本相符，否則可能無法啟動瀏覽器。
